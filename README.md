Práctica 2 Python
Requisitos: 
  - Tener instalado Python y un entorno (Visual studio code)
  - Crear el entorno virtual con: python -m venv .venv
  - Activar el entorno dependiendo de Windows, Linux o Mac. En windows: .venv/Scripts/activate
  - Instalar las versiones de paquetes necesarios: pip install -r requirements.txt (Mi archivo requirements
  - incluye las siguientes versiones: ipykernel == 7.2.0, jupyterlab == 4.5.6, notebook == 7.5.5)

Estructura del proyecto:
  - notebooks --> contiene los archivos .ipynb (JUPYTER)
  - src --> son las funciones declaradas y la lógica
  - requirements.txt --> lista de dependencias y versiones
  - README.md --> instrucciones del proyecto

Para la ejecución del código, tenemos que entrar en notebooks, abrir el archivo .ipynb, correspondiente 
al ejercicio 10 (competenciaCocina), seleccionar el kernel y ejecutar las celdas.
